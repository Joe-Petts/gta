# GTA – First Drive (Prototype 0.1)

Eigenständiges 2D-Top-Down-Fahrspiel für Windows, entwickelt mit Godot 4.3+.

## Starten
1. Godot 4 (Standard Edition) installieren.
2. Dieses Repository herunterladen oder klonen.
3. `project.godot` in Godot importieren.
4. Mit F5 starten.

## Steuerung
- WASD / Pfeiltasten: Zu Fuß bewegen bzw. fahren und lenken
- E: In der Nähe des gelben Autos einsteigen / aussteigen
- Leertaste: Bremsen

## Aktueller Stand
Ein früher **ungetesteter** Godot-Prototyp mit prozedural gezeichneter Stadt, Spielfigur, Auto und Kamera. Noch **keine** Windows-EXE, keine Kollisionen, Verkehrs-KI, Missionen oder Spielstände.
